2. **Kiểm tra đa mặt phẳng (Multi-Plane Enforcement — kế thừa bài học `L-29` của P1):**

   - **Plane 4 — Generic `frappe.client.*`:** `get`, `get_list`, `get_count`, `get_value`, `insert`, `save`, `set_value`, `bulk_update`, `delete`, `validate_link`.
   - **Plane 5 — Desk / List / Filter / Search / Export & Private Files:** `frappe.desk.form.load.getdoc`, `frappe.desk.form.save.savedocs`, `frappe.desk.reportview.get`, `frappe.desk.reportview.export_query`, `frappe.core.doctype.data_export.exporter.export_data`, `frappe.desk.search.search_link`, `frappe.desk.search.search_widget`, `/private/files/...`, `/cskh/*`, và `12` phép dò filter/order/group/aggregate oracle trên các trường `permlevel = 1`.
3. **Positive Control + Quét Raw & Unicode-Decoded JSON + Hậu kiểm MariaDB:**
   - Mọi phép thử âm đều đi kèm positive control `HTTP 200` của đúng actor sở hữu hợp lệ, quét cả chuỗi JSON thô lẫn JSON đã giải mã `\uXXXX` Unicode để chống lọt tiếng Việt có dấu, và đối soát trực tiếp bảng MariaDB.
